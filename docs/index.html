Detalhes Técnicos

Conheça os componentes

🎮

Microcontrolador

ESP32 DevKit V1

Processador principal com Bluetooth BLE integrado, pequeno, barato e fácil de programar

⚡

Motor de Vibração

Mini motor 3V–5V

Tipo moeda ou cilindro para criar os padrões de feedback tátil

🔋

Transistor (IMPORTANTE)

NPN ou MOSFET

2N2222, BC337 ou IRLZ44N - Necessário pois ESP32 não aguenta ligar motor direto

🛡️

Diodo de Proteção

Diodo 1N4007

Proteção contra retorno de corrente e circulação indesejada

📊

Resistores

Resistor 1kΩ

Controlam corrente na base do transistor

🔌

Bateria LiPo

3.7V 500mAh

Alimentação compacta e leve para a pulseira

🔋

Módulo de Carregamento

TP4056

Permite carregar as baterias com proteção integrada

📦

Case/Estrutura

Impressa em 3D, caixa plástica ou pulseira fitness reutilizada

🔨

Ferro de Solda

1x Equipamento

Para conexões de componentes seguras e confiáveis

🌊

Estanho

1x Carretel

Material para soldagem de componentes eletrônicos

📏

Multímetro

1x Equipamento

Essencial para testar e diagnosticar problemas

🧩

Protoboard

1x Unidade

Para testes rápidos antes de soldagem definitiva

🔌

Cabos Jumper

Vários

Diferentes comprimentos para conexões flexíveis

💾

Arduino IDE

Software

Instalado no computador para programação

Com driver ESP32 configurado
🖥️

Arduino IDE

No Computador

Interface de desenvolvimento para programar o ESP32

🔌

Driver ESP32

No Computador

Permite comunicação entre computador e microcontrolador

📡

Biblioteca BLE

No Computador

Para comunicação Bluetooth Low Energy

📱

App Android

No Celular
Integração com Google Maps ou Waze
1

Teste Individual

Fazer ESP32 vibrar com botão e testar motor + transistor em protoboard

2

BLE Básico

Conectar celular no ESP32 e enviar comandos LEFT / RIGHT manuais

3

Integração Maps

Capturar notificações, filtrar "esquerda"/"direita" e enviar via BLE

4

Miniaturização

Soldar tudo, case final e ajustar bateria para uso portátil

📡 Lógica de Comandos BLE

Comando: LEFT
Vibra pulseira esquerda - indica virada para esquerda
Comando: RIGHT
Vibra pulseira direita - indica virada para direita
